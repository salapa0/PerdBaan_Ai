# public: files the app loads

| Folder | What it holds |
| --- | --- |
| `fonts/` | Noto Sans Thai, bundled so Thai looks right offline |
| `demo-photos/` | Photos of the demo homestay (the six listed in `src/data/demoHomestay.js`, plus a dark extra) |
| `agoda/` | Simulated Agoda sign-up pages (`agoda-01` … `agoda-08`, `agoda-live`). The current app does not show them: the coach draws its own placeholder pages. Only the older screens (see `src/README.md`) used these |

Keep every image under 500 KB.
