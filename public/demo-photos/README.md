# public/demo-photos

Photos of the demo homestay. Shift+L adds `01-front.jpg` … `06-activity.jpg` to the form and the preview (the first one is the cover). `07-extra-dark.jpg` is an extra, intentionally dark photo for the older "brighten" button, which the current form does not have. The current files are illustrated placeholders; replace them with real photos using the same file names.

Landscape 4:3, about 1600 px wide, under 500 KB each.
