# public/demo-photos

**What goes here:** the photos of the demo homestay (rooms, view, food, entrance). The app shows these when you press "Load demo homestay".
**Who:** C (content and data).

Resize each photo to under 500 KB before adding it. Use simple names like `room-1.jpg`, `view.jpg`. Aim for at least 5 photos, because the checks warn when there are fewer.
