# docs: decisions and plans (written notes)

**What goes here:** text that explains what we decided and what we are building. People read it, the app does not.
Update it when a decision changes.
**Not here:** code, photos, screenshots or slides.

| File | Read it when |
| --- | --- |
| `project-baseline.md` | **Start here.** The whole project in one place: what we build, what is decided, open questions |
| `demo-mvp-scope-local.md` | You need to know what we code, what we fake and what we skip for the demo |
| `prototype-build-spec.md` | You need the tech stack and the build order |

If two files disagree, `demo-mvp-scope-local.md` wins for the build, and `project-baseline.md` wins for everything else.
